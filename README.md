# BEELY

# 🛍️ Frontend Social Media – React + React Router DOM + Context API

BEELy es una red social que permite a los usuarios registrarse, iniciar sesión, compartir publicaciones y actualizar su perfil. 
Combina un frontend en React con Redux Toolkit y un backend en Node.js/Express, ofreciendo una experiencia social rápida, interactiva y escalable.

---

## 📌 Acerca del proyecto

El proyecto combina un frontend dinámico con React y Redux Toolkit, y un backend robusto en Node.js y Express, conectado a una base de datos para manejar autenticación, publicaciones y perfiles de usuario. 
BEELy busca ofrecer una experiencia social segura, rápida y amigable, integrando funcionalidades esenciales de interacción online con un enfoque escalable para futuras mejoras.

---

## 🛠 Tecnologías usadas

- **React**: Librería principal para construir la interfaz.
- **React Router DOM**: Para la navegación entre páginas.
- **Context API + useReducer**: Para el estado global de usuario y posts.
- **Axios**: Para peticiones HTTP a la API backend.
- **SASS (SCSS)**: Para estilos limpios, reutilizables y organizados.
- **LocalStorage**: Para persistir el login y el token de sesión.

---

## 🧩 Funcionalidades implementadas

- Registro y login de usuarios
- Vista de dashboard
- Posts
- Perfil de usuario 
- Buscador de post y usuarios

## 🚀 Cómo instalar y ejecutar el proyecto

1. Clonar el repositorio:

```bash
git clone 
cd socialmedia
```

2. Instalar dependencias:

```bash
npm install
```

3. Ejecutar el servidor:

```bash
npm run dev
```

> Asegúrate de tener el backend corriendo en `http://localhost:5000`
